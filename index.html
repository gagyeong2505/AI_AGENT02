BASIC 08

CLI · GitHub · Antigravity 준비

문서 자동화 Skill을 확장하기 전에 터미널 명령으로 여러 도구를 연결하는 기본 흐름을 정리합니다.

CLI란 무엇인가

Command Line Interface는 텍스트 명령으로 프로그램을 직접 제어하는 방식입니다. Claude Code, GitHub CLI, Antigravity CLI처럼 각각의 도구를 명령어로 호출하고 결과를 다음 작업에 연결할 수 있습니다.

명령어 기본 구조 
[도구] [명령] [--옵션] [인수]

Claude Code

파일 편집, 코드 실행, MCP, Skill 실행을 담당합니다.

GitHub CLI

저장소, PR, 이슈를 터미널에서 관리합니다.

Antigravity CLI

터미널에서 Google Antigravity에 직접 질문합니다.

Claude Code CLI

  • + 자동화와 스크립팅에 적합
  • + Hooks, Skills, MCP 같은 고급 기능 지원
  • + 반복 작업과 파이프라인 연결에 강함
  • - 터미널 기본 지식이 필요하고 시각적 작업에는 불편할 수 있음

Claude Desktop

  • + GUI 기반이라 비개발자도 접근하기 쉬움
  • + Projects 단위 관리와 파일 드래그앤드롭에 편리
  • + CLI와 세션 공유 가능
  • - 고급 자동화 스크립팅과 파이프라인 연결에는 제한이 있음

GitHub 계정과 CLI 인증

GitHub는 코드 버전 관리, 원격 저장소 백업, 팀 협업의 기반입니다. GitHub CLI를 인증해두면 저장소, PR, 이슈 작업을 Claude Code와 연결할 수 있습니다.

GitHub 가입 
github.com/signup
Windows 설치 
winget install GitHub.cli
macOS 설치 
brew install gh
인증 확인 
gh auth status
스코프 지정 인증 
gh auth login --scopes repo,delete_repo,workflow,gist,read:org,admin:public_key,write:packages

GitHub CLI Skill 실습

저장소 목록 
gh repo list
PR 목록 
gh pr list
이슈 목록 
gh issue list
Claude 요청 
gh cli로 내 저장소 목록과 최근 PR 상태를 정리해주는 스킬을 만들어줘

Antigravity CLI 실습

Antigravity CLI의 비대화형 호출을 사용하면 질문을 보내고 응답을 바로 받을 수 있습니다. Claude 안에서 이 명령을 호출하는 Skill을 만들면 두 AI를 함께 쓰는 흐름이 됩니다.

설치 
curl -fsSL https://antigravity.google/cli/install.sh | bash
기본 사용법 
agy -p "질문이나 지시사항"
직접 질문 
agy -p "Claude Code와 Antigravity CLI의 차이점을 간단히 설명해줘"
Claude 요청 
bash로 agy -p 를 호출해서 내 질문에 Antigravity가 답하는 스킬을 만들어줘

연결 목표

Claude Code + GitHub CLI + Antigravity CLI를 조합하면 저장소 상태를 확인하고, 외부 AI에게 의견을 묻고, 그 결과를 Skill 자동화로 이어가는 파이프라인을 만들 수 있습니다.

ADV 01

엑셀 · 워드 · PPT · 한글 문서 자동 작성

4종 오피스 문서를 자동 생성하는 Python Skill을 만들고, 하나의 에이전트 명령으로 문서 파이프라인을 연결합니다.

엑셀 분석 Skill

openpyxl · 매출 데이터 분석

`매출데이터_템플릿.xlsx`를 읽어 월별 합계, 평균, 최대 거래처를 계산합니다.

워드 보고서 Skill

python-docx · 템플릿 치환

보고서 템플릿의 플레이스홀더를 분석 결과로 채워 `report.docx`를 생성합니다.

PPT Skill

python-pptx · 발표자료 생성

회사 범용 템플릿 9장 구조에 맞춰 조사 내용과 요약을 발표자료로 만듭니다.

한글 Skill

python-hwpx · ZIP-level 치환

`gonggong` 템플릿 기반으로 .hwpx 보고서를 생성하고 브라우저에서 검토합니다.

오늘의 목표

엑셀 데이터 하나를 입력하면 워드, PPT, 한글 보고서가 동시에 생성되는 자동화 흐름을 설계합니다.

REVIEW

라이브러리란?

직접 만들 필요 없이 설치해서 바로 사용하는 기능 묶음입니다. 오늘은 문서 파일을 다루는 Python 라이브러리를 Skill로 감쌉니다.

사용 방식

pip install openpyxl
import openpyxl

오늘 사용할 라이브러리

  • openpyxl엑셀 .xlsx
  • python-docx워드 .docx
  • python-pptxPPT .pptx
  • python-hwpx한글 .hwpx
Claude에게 Skill 생성을 요청하면 `pip install`, `import`, 파일 입출력 코드를 함께 구성하도록 지시할 수 있습니다.

BASIC 02

워드 보고서 Skill

`python-docx`로 보고서 템플릿의 제목, 개요, 표, 결론 영역을 자동으로 채웁니다.

템플릿 치환 패턴

doc = Document('보고서_템플릿.docx')
for p in doc.paragraphs:
    if '[보고서 제목]' in p.text:
        p.runs[0].text = '실제 보고서 제목'
doc.save('out.docx')

실습 프롬프트

"엑셀 분석 결과를 바탕으로 보고서_템플릿.docx 양식에 맞게 보고서 만들어줘"

PPT Skill

prs = Presentation('회사_범용_템플릿.pptx')
slide = prs.slides[3]  # 내용 슬라이드
for shape in slide.shapes:
    if shape.has_text_frame:
        shape.text_frame.text = '새 내용'

BASIC 04

한글 Skill

`python-hwpx`와 gonggong 템플릿을 사용해 .hwpx 보고서를 생성합니다.

4단계 워크플로우

  1. 1. 복사report-template.hwpx 복사
  2. 2. 조사ObjectFinder로 플레이스홀더 확인
  3. 3. 치환zip_replace()로 내용 변경
  4. 4. 후처리fix_namespaces.py 실행

실습 프롬프트

"gonggong report-template.hwpx로 [주제] 보고서 만들어줘"

생성된 파일은 `hwp.polarisoffice.com`에서 설치 없이 열어 확인합니다.

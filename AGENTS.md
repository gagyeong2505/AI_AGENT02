# AGENTS.md

## Image Attachment Rule

When the host provides a path to an image, do not insert or attach the image directly as-is.

Instead:

1. Analyze the image saved at the provided path.
2. Compare the analysis with the contents of the other tabs.
3. Unify the result with the existing design rules, tone, layout, and visual style used across those tabs.
4. Attach or place the processed result only in the location explicitly instructed by the host.

## Korean Instruction

호스트가 이미지 경로를 입력하면, 해당 경로에 저장된 이미지를 직접 삽입하지 않는다.

반드시 이미지를 먼저 분석한 뒤, 다른 탭의 내용들과 디자인 규칙을 통일하여 호스트가 명령하는 위치에 첨부한다.
